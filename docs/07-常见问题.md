# 第一次接触时，常见的四个疑问

## 完全不会写代码，也能开始吗？

可以先完成需求说明、模拟流程和测试集，理解工作方式。要独立开发和维护客户系统，还需要补编程、接口、数据、调试与部署基础。手动演示是起点，不等同于可上线的软件。

## FDE 和普通开发工程师有什么不同？

岗位有重叠。FDE 通常更贴近具体客户，除实现功能外，还会负责需求澄清、系统集成、实际使用与交接。不同公司的职责差别很大，判断时看实际工作内容。

## 一定要会训练模型、做多 Agent 吗？

本指南的入门项目不需要。先学会使用模型、接入数据、验证结果和处理异常。是否需要训练模型或多 Agent，应该由具体问题决定。

## 什么时候可以接入真实业务？

在模拟数据与测试流程跑通之后，先选择小范围、可回退的试点；由业务负责人确认规则和验收方式，落实数据访问权限与人工审核。能演示不代表可以直接自动操作真实订单。
