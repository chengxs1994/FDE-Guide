# 资料不用全看，按当前缺口选一份

以下为已查阅的原作者或官方资源。课程内容、收费和认证安排可能变化；以链接页面为准。本文练习与七天路线为独立整理，不是这些课程的官方课程表。

1. **[FDE Lab · 学习与实践路线](https://fdelab.dev/learn/)**<br>
   英文，29 个里程碑，包含练习与验收证据。先看“Understand the workflow first”，练习访谈和一页需求说明；已有编程基础可跳过基础部分。
2. **[Hugging Face · AI Agents 中文课程](https://huggingface.co/learn/agents-course/zh-CN/unit0/introduction)**<br>
   免费学习材料，要求 Python 基础。先学第 1 单元的模型、工具和 Agent 概念，再选一个框架做案例。页面保留旧认证截止日期，不应据此承诺现在能领取证书。
3. **[FDE Practical Guide · 实用手册](https://github.com/abhishekbhartiind/forward-deployed-engineer)**<br>
   英文公开指南，含 12 周路线、需求模板和项目建议。做完第一轮练习后，按“需求 → 集成 → 部署 → 测量”补齐项目；当前内容标注为 v0.1。
4. **[Awesome FDE Roadmap · 能力地图](https://github.com/pierpaolo28/Awesome-FDE-Roadmap)**<br>
   英文公开资源，覆盖数据、云、AI、评估和咨询沟通。适合用作后续检索目录，不建议小白从头到尾逐项学习。
5. **[Edward Donner · AI FDE 课程配套资料](https://edwarddonner.com/2026/10/14/ai-fde-the-forward-deployed-engineer-agentic-ai-architect/)**<br>
   英文，含实验与代码分支入口。适合希望跟着视频做项目的人。配套网页可读不等于完整视频课程免费；调用模型、使用云服务也可能产生费用。

**最短学习顺序：**本指南的 90 分钟练习 → FDE Lab 的需求部分 → Python 基础 → Hugging Face 的 Agent 基础 → 回到同一个项目补齐集成、评估和交接。
